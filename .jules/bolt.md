## 2024-11-06 - In-Memory Caching for Local Static JSON Fetching
**Learning:** In a vanilla client-side app where large static `.json` files are fetched locally instead of using a true backend or bundler, rapid UI interactions (e.g. switching between topics/subjects) can trigger redundant network requests and expensive `JSON.parse` operations that block the main thread. Browsers do not always optimally cache these large local file requests by default in such custom switching workflows.
**Action:** Implement a simple in-memory `cache` object on the global application state to store parsed JSON responses, and intercept future fetch attempts by checking this cache first. This significantly reduces I/O wait and `JSON.parse` main-thread blocking when navigating between previously viewed subjects.
